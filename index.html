Installer BOUA AI sur tous vos appareils

Installation directe disponible !

Ajoutez BOUA AI comme application native sur cet appareil.

🤖 Android (Chrome / Edge)

1. Ouvrez le menu ⋮ en haut à droite.
2. Appuyez sur « Ajouter à l’écran d’accueil » ou « Installer l’application ».

🍎 iPhone & iPad (Safari)

1. Appuyez sur le bouton Partager (carré avec flèche).
2. Sélectionnez « Sur l’écran d’accueil ».

💻 Windows / Mac / Linux

Cliquez sur l’icône Installer (⊕) dans la barre d’adresse de Chrome, Edge ou Brave.

📦 Package Android APK

Téléchargez le pack complet avec capacitor.config.json pour générer l’APK Android Studio.

Déployer BOUA AI sur GitHub, Vercel & Firebase

Pack Complet Prêt à Déployer (Tout-en-Un)

Contient index.html, manifest.json, sw.js, vercel.json, firebase.json, capacitor.config.json et README.md.

1. GitHub (Dépôt & GitHub Pages) 
git init && git add . && git commit -m "Deploy BOUA AI" && git branch -M main && git push -u origin main
2. Vercel (Déploiement Production instantané) 
npx vercel --prod
3. Firebase Hosting (Google Cloud) 
npm install -g firebase-tools && firebase login && firebase deploy --only hosting
